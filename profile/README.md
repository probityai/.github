# Probity

Open source tools for checking AI agent actions. Choose a tool by task.

Explore retained runs or contribute one in the [Open Evidence Lab](https://probityai.github.io/agent-evidence-atlas/lab.html).
Read the [agent guide](https://probityai.github.io/agent-evidence-atlas/llms.txt) for commands and pinned sources.

## Choose a tool

| Task | Project |
| --- | --- |
| Evaluate workload admission policies | [Probity Admission](https://github.com/probityai/agent-evidence-admission/blob/dd0857aea19283185f27a19d07a5c3257ae31ec6/README.md) |
| Inspect recorded claims and retained runs | [Probity Atlas](https://github.com/probityai/agent-evidence-atlas/blob/1f1a44fab47cba2d0fb032924d4af838063919b3/README.md) |
| Sign and verify DSSE envelopes in Rust | [dsse](https://github.com/probityai/dsse/blob/de6234846a9f60090d2a5ad4634dc7f725479a14/README.md) |
| Admit and canonicalize JSON in Rust | [jcs-admit](https://github.com/probityai/jcs-admit/blob/ecc8b5ef4b380a2fe38e5079d128307a1c702717/README.md) |
| Record file actions or check native delegation evidence | [Probity Observer](https://github.com/probityai/agent-evidence-observer/blob/3ea9f35a9b775539cd37a15f8e05916f9eb4f333/README.md) |
| Test a verifier against conformance cases | [Probity Vectors](https://github.com/probityai/agent-evidence-vectors/blob/700f869447b8416bc53b75cfecd42e1135c1c1da/README.md) |
| Check a claim against pinned evidence | [Probity Verify](https://github.com/probityai/probity-verify/blob/e835ce2bd6a960e7a1cc2fa6522f16d55dce728a/README.md) |
| Use shared definitions for agent evidence claims | [Probity Vocabulary](https://github.com/probityai/agent-evidence-vocabulary/blob/8c80579ae613d7ae07982321e13a6091c402b2a8/README.md) |

Each project explains its supported commands and examples in its README.
Retained runs keep source revisions, readers, operators and rerun instructions with the result.
