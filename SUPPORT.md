# Getting help

- **A question or a usage problem:** open an issue in the repository for the
  tool you are using. Include the version (`pip show <package>` or the tag you
  pinned) and the command or bytes that show the problem.
- **A bug or a wrongly judged record:** open an issue with the input that
  reproduces it. See [CONTRIBUTING.md](CONTRIBUTING.md) for what makes a report
  easy to act on.
- **A security problem:** do not open an issue. Follow
  [SECURITY.md](SECURITY.md) and report it privately.
- **Where to start:** the [profile page](https://github.com/probityai) lists the
  tools and which one fits which check.
